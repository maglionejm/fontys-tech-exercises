---
name: summarize-brief
description: Turn one library document into a five-line brief with exactly one concrete number or date per line.
---
1. Read the document in full with read_doc.
2. Write five lines. Each line states one fact and carries one number or date from the text.
3. Keep the document's wording for the facts; do not add outside knowledge.
4. End with a single [source: <doc id>] tag.
Use template.md for the layout.
