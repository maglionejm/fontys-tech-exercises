# The Model Context Protocol

The Model Context Protocol, MCP, is an open standard for connecting language model applications to tools and data sources. Anthropic open-sourced the Model Context Protocol on 25 November 2024, with launch partners including Block and Apollo and development tool makers Zed, Replit, Codeium and Sourcegraph.

An MCP server exposes tools, resources and prompts over a common message format; an MCP client, such as a chat application or a coding agent, can connect to any server without custom integration code. In plain words, MCP is a standard plug: any tool server fits any model client.

Adoption was fast. On 26 March 2025 OpenAI announced support for MCP in its Agents SDK, with the ChatGPT desktop application and the Responses API to follow. Google DeepMind also adopted the protocol in 2025. By 2026 MCP is the default way harnesses discover and call external tools.

Sources: Anthropic, "Introducing the Model Context Protocol", 25 November 2024. Sam Altman on X, 26 March 2025. Wikipedia, "Model Context Protocol".
