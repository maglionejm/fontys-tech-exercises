---
name: safe-calculations
description: Do every calculation with the calculator tool, never in your head, and show the exact expression you evaluated.
---
1. Extract the numbers and the operation from the task.
2. Call calculator with one expression using + - * / ** % and parentheses.
3. Report the result together with the expression, for example "(891 - 179) / 891 = 0.799".
4. If the task mixes a lookup and a calculation, look the numbers up first, then calculate.
