# Lab project for Module 5, Harness Engineering

This folder is the hands-on project for the two Claude Code labs of Module 5 (sessions 2 and 4). It is deliberately small so that every answer can be checked by opening a file.

## What counts as "the repository" here

- `docs/` holds the only content the labs ask about: `module-overview.md`, `glossary.md` and `faq.md`.
- `.claude/skills/` holds the procedures Claude Code can load on demand (see lab 2).
- `.claude/agents/` and `.claude/settings.json` are added in lab 4 (subagents, hooks, permissions).

## Rules for working in this folder

- Read before you answer. Never invent numbers, dates or names.
- Cite every fact with its file, as `Source: docs/<file>.md`.
- If the answer is not in `docs/`, say so plainly and name the files you checked.
- Do not modify files under `docs/` unless the user asks for it.
- Never read or print `.env` files. Keys live outside this folder.
- Keep answers short: one to three sentences, then the source line.
